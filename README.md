# Практична робота №6. Автоматизоване тестування та розгортання Python-сервісу

## Мета проєкту
Побудова повного DevOps-процесу (CI/CD), який автоматично перевіряє код за допомогою тестів, збирає та розгортає застосунок у контейнері, контролює його працездатність та дозволяє відкочувати непрацездатні версії.

## Структура файлів та їх призначення
* **`app.py`** — реалізація основної логіки вебзастосунку на Flask (маршрути `/health` та `/version`).
* **`requirements.txt`** — фіксація та керування залежностями Python (Flask, Gunicorn, pytest, requests, pytest-testinfra).
* **`Dockerfile`** — інструкція зі створення безпечного Docker-образу (запуск від не-root користувача `appuser`).
* **`compose.yaml`** — конфігурація та оркестрація сервісів через Docker Compose з налаштованим `healthcheck`.
* **`.env.example`** — шаблон змінних середовища для налаштування конфігурації.
* **`tests/test_api.py`** — модульні тести `pytest` для перевірки API-маршрутів, параметризації та використання `monkeypatch`.
* **`tests/test_infra.py`** — інфраструктурні тести для перевірки роботи процесу `gunicorn`, прав користувача та доступності порту.
* **`.github/workflows/ci-cd.yaml`** — конфігурація автоматизованого конвеєра CI/CD у GitHub Actions.
